## Het probleem

Elke developer stelt zijn eigen skills, MCP's, hooks en agents samen. Die lopen uit de pas, zijn lastig te delen en wie nieuw begint, begint bij nul.

## De oplossing

Eén installatie waarmee iedere CEDA-developer dezelfde, actuele set gebruikt. Verbeteringen komen op één plek terecht en bereiken iedereen automatisch.
