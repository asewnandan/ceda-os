CEDA OS is het framework waarmee CEDA-developers sneller van idee naar product gaan. Je installeert het één keer in je IDE. Een orchestrator-agent doet de rest.

## Hoe het werkt

<Steps>
  <Step>
    ### Installeer één keer
    Eén installatie in je IDE. Geen set die je zelf samenstelt.
  </Step>
  <Step>
    ### De orchestrator kijkt mee
    Hij herkent welk product je bouwt en in welke fase je zit.
  </Step>
  <Step>
    ### De juiste bouwsteen start vanzelf
    Skills, MCP's, hooks en agents worden aangeroepen op het moment dat ze nodig zijn.
  </Step>
</Steps>

## Eén bron van waarheid

Zonder CEDA OS stelt elke developer zijn eigen set samen. Die loopt uit de pas en wie nieuw begint, begint bij nul. Nu is er één actuele set, en verbeteringen bereiken iedereen automatisch.
