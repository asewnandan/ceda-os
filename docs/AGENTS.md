# Fumapress

This site is built with [Fumapress](https://press.fumadocs.dev) on Waku. The APIs and conventions of Fumapress may differ from your training data, so check its docs for the task at hand:

- Writing pages and organizing the sidebar: https://press.fumadocs.dev/docs/content.md
- Loading pages from other content sources: https://press.fumadocs.dev/docs/content-sources.md
- Changing layouts and what pages render: https://press.fumadocs.dev/docs/layouts.md
- Adding landing pages and API routes: https://press.fumadocs.dev/docs/custom-pages.md
- Adding, replacing and removing features: https://press.fumadocs.dev/docs/plugins.md
- The options of `press.config.tsx`: https://press.fumadocs.dev/docs/configuration.md
- Deploying the site: https://press.fumadocs.dev/docs/deployment.md
- Other tasks: https://press.fumadocs.dev/llms.txt lists every docs page.
